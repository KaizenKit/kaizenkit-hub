# KaizenKit Brand Guide

## Tagline

Small tools for better work.

## Mission

Build lightweight tools that save time and simplify repetitive work.

## Design Principles

- Simple
- Fast
- Reliable
- Offline first

## Naming

KaizenKit <Category> <Tool>

Examples:
- KaizenKit CSV Merge
- KaizenKit PDF Merge
- KaizenKit File Rename
